# Data dependencies

The repository includes the inputs of the Saudi Arabian run that are not external datasets, its released outputs and a 15-dam test fixture, but **is not fully self-contained**. The settings files name the external rasters and shapefiles as `/path/to/...`. Set these paths to your own copies before a run. The regression test runs from the repository alone.

## Included assets

`region/ksa/input/` holds the inputs of the Saudi application that are not external datasets, namely the dam catalog in its cleaned and transliterated form with the list of excluded entries and the reason for each, the filtered satellite water-extent series, the upstream catchment area, sediment yield and open-water evaporation of [Dash et al. (2025)](https://doi.org/10.1016/j.jenvman.2025.127199), the GRDL reference curves of the cross-reference dams, the design table and February 2025 sonar survey of Baish and the preprocessing cache. `region/ksa/output/` holds the released tables, check maps, panels and report. `test/fixture/` holds the 15-dam fixture with its inputs, among them the SRTM GL1 elevation clipped to the windows of its dams, and its reference outputs.

## External datasets

The settings file names each external dataset by path.

| Dataset | Source | Purpose |
| --- | --- | --- |
| **SRTM GL1 v003** (1 arc-second, ~30 m) | [doi:10.5067/MEaSUREs/SRTM/SRTMGL1.003](https://doi.org/10.5067/MEaSUREs/SRTM/SRTMGL1.003), 1° `.hgt` tiles at [step.esa.int](https://step.esa.int/auxdata/dem/SRTMGL1/) | SRTM-era topography for the flood fill, acquired February 2000 |
| **MERIT-Basins** (MERIT Hydro v07, Basins v01 bugfix1, one file per Pfafstetter level-1 basin), the vector reaches and unit catchments of MERIT Hydro | [reachhydro.org](https://www.reachhydro.org/home/params/merit-basins), [Lin et al. (2019)](https://doi.org/10.1029/2019WR025287), built on MERIT Hydro, [Yamazaki et al. (2019)](https://doi.org/10.1029/2019WR024873) | River direction and fallback starting points for wall placement. Preprocessing keeps the reaches that intersect the country and all their upstream reaches |
| **Natural Earth admin-0 countries** (1:10 million scale, without boundary lakes) | [naturalearthdata.com](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/) | Country boundary for selecting the river reaches and for the domain map of panel p1 |
| **Dam catalog** (for example `<country>_dams.csv`) | User-provided | Coordinates, design capacity, dam length and height, spillway height and construction year of each dam |
| **Filtered satellite water extent** | User-provided | Water areas for the footprint comparison and for the satellite anchor, an alternative evaluated for the full-pool area of the regionalization |
| **GRDL reference curves** (optional) | GRDL version 2, [Hao et al. (2024)](https://doi.org/10.1029/2023WR035781), dataset on [Zenodo](https://doi.org/10.5281/zenodo.8306604) | Deep-learning reconstruction of reservoir area-storage-depth curves, used in the GRDL comparison panel (`p6_grdl_comparison.png`). Both products use SRTM and GRDL is itself a reconstruction, so the comparison assesses consistency, not accuracy against measured bathymetry |
| **Sonar bathymetry** (optional) | Field survey | Reference curve for an indirect consistency check at one or more reservoirs. The survey describes the reservoir at the survey date, whereas the SRTM-derived curve represents the valley as it stood in February 2000 |
| **Catchment table and open-water evaporation** (optional, KSA-specific) | [Dash et al. (2025)](https://doi.org/10.1016/j.jenvman.2025.127199) | Per-dam upstream catchment area (km²) for the full-pool area regression of the regionalization, delivered sediment yield (t/ha/yr) for the sediment budget, and open-water evaporation (mm/yr), merged into `eaves_summary.csv` when `sedimentation_dir` is set |
